## How to Run

1. Install Python.
2. Install required libraries:

```bash
pip install numpy pandas jupyterlab
```

3. Start Jupyter Notebook or JupyterLab:

```bash
jupyter notebook
```

or

```bash
jupyter lab
```

4. Open any `.ipynb` file to explore the code.
